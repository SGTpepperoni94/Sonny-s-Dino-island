# Known Gotchas — Pirate & Dino Island Discovery

1. **Quaternius Manifest Base URL & Format Quirk**: The pinned manifest uses top-level `"assets"` mapping model keys to `.gltf` files (e.g. `"Characters_Henry": "Characters_Henry.gltf"`). Always override `manifest.baseUrl` with the pinned jsDelivr commit URL (`@d630aa4139033709a52cd6ae8aa314deb77c83c9/models/`) in `AssetManager.ts` so fetches remain immutable. Evict failed `loadingPromises` on timeout/error so retries work.
2. **Shared GLTF Buffer Disposal**: Every cloned GLTF child mesh is tagged `userData.sharedResource = true`. Scene systems (`PropScatterSystem`, `PlayerSystem`) MUST NOT dispose shared GLTF buffers during `resetCycle()` — only `AssetManager.dispose()` disposes cached GLTF buffers.
3. **Animation Clip Name Collisions**: Quaternius `Characters_Henry` has both `Idle` and `Jump_Idle`. Always exact-name match before substring fallback, and transition via `mixer.stopAllAction(); action.reset().fadeIn(0.12).play();`.
4. **Software WebGL Loop Starvation**: In headless Chromium / SwiftShader, unpaced `requestAnimationFrame` starves browser input & screenshots. `GameEngine` detects software WebGL via `UNMASKED_RENDERER_WEBGL`, disables AA/shadows, skips `renderer.compile()`, caps pixel ratio to `1`, and paces frames via WebGL2 `fenceSync` (`afterDraw()`).
5. **No `backdrop-blur` Over WebGL**: Keep all HUD/Title overlays free of CSS `backdrop-filter` to avoid frame stalls over the live canvas.
6. **UI Click Pass-Through**: `InputManager` checks `target.closest('button, input, [data-ui-interactive="true"]')` so HUD taps never trigger click-to-run on terrain.
7. **Single-Sample-Per-Frame Input**: `GameEngine.tick()` calls `input.sample(dt)` strictly once before updating systems, and both `PlayerSystem` and `CameraSystem` read `input.getState()`. Never call `input.sample()` inside individual gameplay systems or frame-scoped right-drag / Q-R / gamepad camera orbit deltas will be zeroed before `CameraSystem` reads them.
8. **Headless `?autostart=1` AudioContext Autoplay Guard**: `AudioEngine.unlock()` checks `navigator.userActivation?.hasBeenActive` before instantiating `AudioContext`, so programmatic `?autostart=1` sessions stay at zero console warnings while real user gestures unlock audio immediately.
